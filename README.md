## Тестировалось на версии Python 3.14

Требования:
* Установленный python
* Библиотека windows-curses

Инструкция к запуску:
* Скачать python с официального сайта
* Установить библиотеку curses командой: "pip install windows-curses"
* Запустить игру python snake_game.py (через Powershell/CMD, либо Visual Code и тд.)
